# 1.22.1 — PiP activation and visible player controls

- Preserve the toolbar click gesture through Chrome API callbacks when selecting a player and requesting native PiP.
- Initialize missing content scripts in already-open tabs after install/reload, then wait for site policy and settings before choosing a player.
- Show the optional page button beside a loaded, visible video, including embedded players. Remove it when the video is hidden, removed or scrolled out of view; do not show it on empty pages.
- Open PiP directly from the local page-button click and show actionable toolbar tooltips for gesture, policy and unsupported-player errors.
- Add Chrome toolbar-action tests with page gestures expired, page-button visibility/iframe tests, and recovery for an existing tab after reinstall.

Reload the extension at `chrome://extensions` after updating. If old controls remain, reload the video tab once.

This repairs native single-window PiP in Chrome. The multi-view feature still uses ordinary browser windows and does not provide multiple always-on-top native PiP windows.
