# Floating Video Toolkit 1.21.0

This release improves dependable playback control and adds ultrawide viewing tools.

- Choose original, fit, fill, or stretch, with Auto/16:9/21:9/32:9/4:3 player shapes, crop zoom, and pan controls.
- Open an in-page cinema player or a mini-player that snaps to four corners. Use its buttons or optional number keys; Escape returns the video.
- Assign shortcuts for play/pause, separate play/pause/mute/unmute, layouts, crop, and corners. Playback commands follow native PiP across tabs.
- Apply exclusions to the top page and its embedded players, and select only one frame for each action.
- Restore video flags, owned styles, caption modes, and playback control on disable. Cancel pending caption fetches and keep the audio destination connected when turning smart speed off.
- Use clearer settings, error feedback, site exclusions, and actual shortcut bindings. Experimental features are opt-in for new installs.
- Install the tested extension ZIP and verify its SHA-256 checksum.

Corner snapping and crop/picture controls apply to the page player. Native PiP placement remains browser-controlled. In-page layouts require a top-page video. Live streaming-service and DRM compatibility varies; experimental caption rendering is not guaranteed.

Extract the ZIP, open `chrome://extensions`, enable Developer mode, and load the extracted folder. After upgrading, reload the extension and your video tabs.
