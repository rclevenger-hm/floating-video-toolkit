# 1.22.2 — Bring browser pop-outs to the front

- Open browser pop-out players with foreground focus instead of explicitly creating inactive windows.
- Open the companion audio mixer without taking focus from the requested player; reuse an existing mixer without raising it.
- Restore minimized windows when using **Focus**, requesting an existing pop-out, or explicitly opening the mixer. Preserve maximized/fullscreen state otherwise.
- Add regression coverage for foreground requests, companion mixer focus, and minimized-window restoration.

Reload the extension at `chrome://extensions` after updating.

These changes apply to ordinary browser pop-outs. They do not make pop-outs always on top or fix native PiP appearing behind another application. Chrome and the OS manage native PiP's window order; the video PiP API exposes no focus or always-on-top control. Desktop stacking behavior still needs manual verification on the affected system.
